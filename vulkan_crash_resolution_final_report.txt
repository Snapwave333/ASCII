ROOT CAUSE ANALYSIS
-------------------
The crash was caused by multi-GPU driver conflicts between:
- NVIDIA GeForce RTX 4070 Laptop GPU (Primary discrete GPU)
- Intel UHD Graphics (Integrated GPU)

The Vulkan loader was attempting to initialize both GPU drivers simultaneously, leading to
a memory access violation during instance creation. This is a known issue on systems with
mixed GPU vendors where the Vulkan loader cannot properly handle multiple ICD (Installable
Client Driver) configurations.

SOLUTION IMPLEMENTED
--------------------
Successfully implemented the "Ultra-Minimal NVIDIA" configuration that forces single GPU
usage and disables problematic validation layers:

Environment Variables Applied:
- VK_ICD_FILENAMES=C:\Windows\System32\DriverStore\FileRepository\nvami.inf_amd64_f6ed7dd5d89ca48a\nv-vk64.json
- VK_INSTANCE_LAYERS= (empty - disables all layers)
- VK_LOADER_LAYERS_DISABLE=1 (disables loader layer management)
- DISABLE_VULKAN_VALIDATION=1 (disables validation system)
- VK_KHRONOS_validation=disable (specifically disables Khronos validation)
