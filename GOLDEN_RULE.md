# Golden Rule
Never use fake, mock, simulated, or placeholder assets or code.
- No functions left as "TODO", "stub", or "not implemented".
- No placeholder textures, fonts, ASCII frames, or config values.
- All logic must be executable, compilable, and wired into the main loop.
- All assets must be real files from this repo or properly licensed free sources.
- Any temporary shim must be clearly marked with a ticket/issue and a removal plan.
